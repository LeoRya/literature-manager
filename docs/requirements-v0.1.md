# 本地文献管理系统 v0.1 需求

## 产品目标

提供一个单用户、本地优先的桌面文献库。用户选择文件夹后，系统递归发现其中的 PDF，建立结构化索引，同时保持原文件的名称、位置和内容不变。

## v0.1 范围

- 递归扫描 PDF，扩展名不区分大小写。
- 只读取并建立索引，不移动、重命名或删除文件。
- 增量处理新增、修改、移动和缺失文件。
- 保存标题、作者、DOI、发表日期、年份、关键词、期刊、摘要、文件位置、自定义标签、识别状态、可信度和备注。
- 按在线 DOI 元数据、PDF 元数据、正文启发式识别、文件名的优先级补全信息。
- 在线补全优先使用 Crossref，OpenAlex 作为回退。
- 通过 DOI、SHA-256、标题与年份识别重复文献；一篇文献可关联多个位置。
- 固定字段与扁平自定义标签分开管理。
- 低可信、无文字层或解析失败的 PDF 进入待确认/失败列表。
- 用户可编辑全部元数据、标签和备注，并标记为人工确认。
- 全局搜索覆盖元数据、标签、路径和 PDF 正文。
- 组合筛选支持条件之间及同字段多值之间的 AND/OR。
- 搜索结果可打开 PDF，或在 Finder/资源管理器中显示文件。
- 支持 CSV、BibTeX、RIS 导入与导出。
- 首版不集成 OCR。

## 隐私与数据

- PDF、全文索引和 SQLite 数据库均保存在本机。
- 联网补全只发送 DOI 或候选标题，不上传 PDF 文件或正文。
- 缺失文件只把位置标记为失效，不删除书目记录和用户标签。
- `paper_library.db` 是用户数据，不进入源码仓库。

## 验收标准

- 能选择包含子目录的文件夹并发现全部 PDF。
- 扫描前后原 PDF 路径、文件名和内容不变。
- 重复副本不产生重复书目，并能显示多个位置。
- 第二次扫描能跳过未变化文件并标记缺失位置。
- 能人工校对、自定义标签、全文检索并组合筛选。
- CSV、BibTeX、RIS 均可导入和导出。
